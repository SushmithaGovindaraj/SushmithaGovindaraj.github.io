## ✨ Design Philosophy

**Cybernetic Precision** — A terminal-inspired, data-driven aesthetic that reflects the technical nature of autonomous systems engineering.

### Key Features

- 🎨 **Terminal Green Palette** — Acid Green (#00FF41) + Tactical Dark (#0A0E27)
- ⚡ **Particle System** — Interactive canvas background with neural network visualization
- 💻 **Terminal UI** — Command-line inspired navigation and hero section
- 🔄 **Scroll Animations** — Staggered reveals with IntersectionObserver
- ✨ **Glitch Effects** — Subtle cyberpunk-style hover interactions
- 📱 **Fully Responsive** — Optimized for 375px to 1440px+
- ♿ **Accessible** — WCAG AA compliant, keyboard navigable, reduced-motion support

- **Vanilla JavaScript** — Zero dependencies
- **Canvas API** — Particle system

## 🚀 Quick Start

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/SushmithaGovindaraj/SushmithaGovindaraj.github.io.git
cd SushmithaGovindaraj.github.io
```

2. Open `index.html` in your browser:
```bash
# macOS
open index.html

# Linux
xdg-open index.html

# Windows
start index.html
```

Or use a local server:
```bash
# Python
python -m http.server 8000

# Node.js (http-server)
npx http-server
```

3. Visit `http://localhost:8000`

### GitHub Pages Deployment

This portfolio is designed for GitHub Pages:

1. Create repository: `YourUsername.github.io`
2. Push code to `main` branch
3. Enable GitHub Pages in Settings → Pages
4. Visit `https://yourusername.github.io`

## 🎨 Design System

### Color Palette

| Role | Hex | Usage |
|------|-----|-------|
| Primary | `#00FF41` | CTAs, highlights, terminal green |
| Secondary | `#008F11` | Accents, hover states |

- **Headings:** Inter (Google Fonts)
- **Body:** Inter (Google Fonts)

### Animation Principles

- **GPU-Accelerated:** Only `transform` and `opacity`
- **Smooth Timing:** 150-300ms transitions
- **Reduced Motion:** Full support for accessibility
- **Performance:** 60fps target on all devices

## 🌟 Features

### 1. Particle System

Interactive canvas background with:
- 80 autonomous particles
- Dynamic connections based on proximity
- Mouse interaction (particles respond to cursor)
- Optimized with RequestAnimationFrame
- Disabled on mobile for performance

### 2. Terminal Typing Effect

Simulated command-line typing in hero section:
```javascript
> initializing_portfolio...
> loading_robotics_engineer.profile
> systems_online ✓
```

### 3. Scroll Reveal Animations

Progressive content reveal using IntersectionObserver:
- Threshold: 10% visibility
- Staggered timing for child elements
- Respects `prefers-reduced-motion`

### 4. Glitch Effects

Subtle cyberpunk-style hover effects on:
- Project cards
- Skill cards
- Navigation links

### 5. Responsive Design

Optimized breakpoints:
- **Mobile:** 375px - 767px
- **Tablet:** 768px - 1023px
- **Desktop:** 1024px - 1439px
- **Large:** 1440px+
